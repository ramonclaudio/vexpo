Put your iPhone screenshots here.

Apple requires these sizes, as portrait PNGs.

- 6.7-inch (iPhone 14 Pro Max and 15 Pro Max), 1290x2796 px
- 6.9-inch (iPhone 16 Pro Max), 1320x2868 px

Name the files like this.

- 6.7-inch is `6.7-01.png`, `6.7-02.png`, and so on up to `6.7-10.png`
- 6.9-inch is `6.9-01.png`, `6.9-02.png`, and so on up to `6.9-10.png`

> [!IMPORTANT]
> Apple rejects submissions missing required sizes.
